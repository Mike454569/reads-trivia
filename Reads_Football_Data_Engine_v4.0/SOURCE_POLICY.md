# Reads Football source policy
Use factual data only from approved sources with recorded licensing/provenance.
Do not copy competitors' question wording, articles, layouts, proprietary databases, logos, photos, or protected creative assets.

For every import: store source URL, release/version, retrieval date, file hash, license/attribution requirement, transformation version.

nflverse: current nflreadpy documentation says the majority of nflverse data is broadly CC BY 4.0, with dataset-specific exceptions. Verify the exact dataset and retain attribution.

Derived relationships are tagged DERIVED and keep source provenance.
Publishing gate: all facts needed by a puzzle must be VERIFIED/SOURCE_BACKED and the answer must be unambiguous.
