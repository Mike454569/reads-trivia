# Source notes — v1.3

College-football updater uses published files from the SportsDataverse/cfbfastR-data repository. Preserve source/release attribution and review source-specific terms before redistributing raw source files.

NFL updater uses the official nflverse-data release patterns consumed by nflreadr.

Reads stores source URLs, SHA-256 hashes, transform versions, and import status in `source_releases` where applicable.
